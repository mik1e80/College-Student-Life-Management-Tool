# 双衡 1.7.0 · 独立闹钟页

下载 Assets 中的 `yiri-1.7.0.apk`，直接覆盖安装，保留旧账本、时间安排与任务提醒。

- 新增底部「闹钟」独立页面，支持多个闹钟、标签、仅一次和每周重复；提供每天、工作日、周末快捷选项。
- 安卓使用系统闹钟调度和持续响铃，支持振动、停止和稍后提醒。默认稍后 10 分钟，可调整或关闭；单次最长响 5 分钟。
- 设置页提供通知、准时响铃和锁屏界面授权入口；网页仅支持页面运行时弹窗和声音。
- 修改、关闭、删除闹钟会取消旧调度和稍后提醒，原任务提醒、时间规划和生活费保留。
- 修正任务提醒清理通知的范围，避免影响独立闹钟正在响铃的通知。

详见[闹钟使用说明](../alarms.md)。
