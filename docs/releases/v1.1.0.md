# 一日有数 1.1.0 · 安卓安装包

请在此版本的 **Assets** 中下载 `yiri-1.1.0.apk`，用安卓手机浏览器打开下载文件并按系统提示安装。`Source code` 是项目源码，不是安装包。

支持 Android 8.0 及以上，需可正常工作的现代 Android System WebView。应用不需要 Google Play 服务。iPhone 不能安装 APK。

## 已提供的功能

- 大类、小类三列网格；默认八个大类和三餐小类，可自行添加，分类不删除。
- 每月每日预算、实际记账、预计与实际差值、日/月统计。
- 今日金额可调整；历史已填记录锁定，历史空缺实际金额仅可补录一次。
- 安装包内置所有账本资源，首次启动即可离线使用，不申请联网权限。
- 安卓返回键和未保存确认；JSON 备份、CSV 明细使用系统文件保存窗口。

数据只保存在本应用中，卸载或清除应用数据会删除账本。网页账本与安卓账本分别保存；当前版本支持导出，暂不支持导入。
