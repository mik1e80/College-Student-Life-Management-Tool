# 一日有数 1.3.0 · 分类改名与未记账分类删除

在 **Assets** 下载 `yiri-1.3.0.apk`，直接覆盖安装。请勿先卸载或清除数据，包名和发行签名沿用旧版。

## 本次改动

- 首页、预算计划和大类详情新增「管理分类」。大类、小类名称可修改；分类 ID、预算、周期和实际账目保持关联，历史和导出显示新名称。
- 小类没有任何实际金额记录时可删除。大类下所有小类都没有实际金额记录时可整体删除，初始分类同样适用。
- 检查全部日期及日 / 月 / 年周期；0 元和历史补录也算已有记录。仅有预算、不曾填写实际金额的分类仍可删除。
- 删除前确认影响范围，删除大类会一起移除其小类；相关全部预算和周期设置一并清理。删除不能撤销。有记录时删除按钮禁用，保存前再次检查最新账本。
- 管理分类时保留尚未保存的预算草稿；同级重名在窗口内提示，不改变原账目。

已有连续添加、日 / 月 / 年记账、周期锁定和历史一次补录规则保持。应用仍为离线版，没有应用内自动更新入口。

## 验证

36 项单元测试通过，包含新增 8 项分类管理测试。浏览器核对改名、已有账目保护、重名提示、删除取消及预算草稿保留。安卓构建和模拟器结果在发行前补充。
