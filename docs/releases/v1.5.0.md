# 双衡 1.5.0 · 新名称与黑白界面

在 **Assets** 下载 `yiri-1.5.0.apk`，直接覆盖原「一日有数」。请勿先卸载或清除数据，旧账本和时间安排保留；安装后桌面名称变为「双衡」。

## 本次改动

- 应用更名「双衡」，时间和收支各有安排。网页、安卓桌面名称、导出文件名和安装说明同步更新。
- 全新黑白图标：两块等大的面板分别表示时间与收支，网页 SVG、PNG 以及安卓启动图标保持一致。
- 页面统一白底、黑字、黑色主按钮，导航、日历、分类、预算与统计改用灰色辅助装饰，安卓启动背景同步改白。
- 自由时间仍标绿、未规划仍标红；节余绿色、超支红色和零值默认色保持原规则。
- 沿用原应用包名、发行签名和存储结构，无需迁移账本。
