# 双衡 1.6.0 · 时间任务提醒

在 Assets 下载 `yiri-1.6.0.apk`，直接覆盖安装，保留原账本与时间安排。

## 本次改动

- 新增「任务提醒」设置，总开关由用户开启；新任务默认开始前、结束前各 5 分钟，可分别调整或关闭。
- 安卓前台弹窗、后台系统通知；支持通知权限和准时提醒授权入口，拒绝权限时显示实际状态。
- 跨日任务按真实日期分别提醒一次；修改、删除任务或关闭提醒后自动更新调度，复制昨天会保留每项提醒选择。
- 网页支持页面打开时弹窗；安卓可在后台和正常结束进程后提醒。系统强行停止、勿扰与省电限制可能影响送达。
- 旧任务不自动开启提醒；沿用原存储结构、应用包名和发行签名，支持覆盖升级。

详见[提醒使用说明](../reminders.md)。
