# 一日有数 1.4.0 · 时间与生活费，一起安排

在 **Assets** 下载 `yiri-1.4.0.apk`，直接覆盖安装；请勿先卸载或清除数据。保持原包名与发行签名，保留旧账本。

## 本次新增

- 首页为「生活总览」：上方完整显示 00:00—24:00 时间线，下方保留生活费。底部新增「时间规划」，原预算、分类管理和支出统计继续使用。
- 每天独立安排，可复制昨天。每段一行、按时间排序；全部空档标红，自由时间绿色，普通安排使用默认色，均有文字标记。
- 提供睡觉、自由时间、吃饭时间名称按钮，也可自定义名称和自由时间标记。
- 支持 23:00—次日 07:00，及选择 24:00 开始。跨日会在两天显示，修改或删除作用于整条安排；时间段不能重叠，可以首尾相接。
- 复制昨天仅复制当天可见的已安排部分，复用相同已有安排，任何冲突整次拒绝，重复点击不重复添加。时间安排可改可删，包括历史日期；金额历史锁定规则不变。
- 兼容 schema 1 / 2 的旧账本，补上空时间列表；时间和金额都在本机，完整 JSON 备份包含时间安排。

## 验证

46 项单元测试通过，含新增 10 项时间规则测试。浏览器验证了完整时间线、自由时间、跨日、24:00 起始和复制去重；安卓构建与模拟器结果在正式发行前补充。

详见 [时间管理说明](../time-management.md)、[开发过程](../development-log.md)和[验证记录](../verification.md)。Android 8.0 及以上，需要可用的现代系统 WebView；安装后可离线使用。
