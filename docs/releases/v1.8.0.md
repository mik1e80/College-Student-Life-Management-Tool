# 双衡 1.8.0 · 分类删除与完整备份恢复

下载本页 Assets 中的 `yiri-1.8.0.apk`，直接覆盖安装；不要先卸载或清除数据。

- 首页大类、小类网格及预算计划直接提供「删除」。删除前确认范围；已有实际记录的分类不可删除，0 元、历史记录和旧计费周期同样受保护。
- 预算页删除后保留其他未保存金额和周期；分类删除同时清理其预算与周期设置。
- 「我的账本」新增完整 JSON 恢复：文件校验、时间和数量预览、明确确认、完整替换；支持旧版备份。
- 恢复前自动保留当前账本，在「恢复前的账本」找回。副本或主账本写入失败不会部分覆盖；不支持合并。
- 网页与 APK 可通过 JSON 手动迁移。恢复的闹钟及任务提醒默认关闭，请核对后开启。
- 整理当前验证摘要、使用指引和后续计划，实体 Android / iPhone 尚未验证的项目单独列明。
