# 一日有数 1.2.0 · 按天 / 月 / 年记账

在 **Assets** 中下载 `yiri-1.2.0.apk`，安卓手机打开后直接覆盖安装。请不要先卸载：新版沿用原包名与发行签名，旧账本会自动兼容。

## 本次改动

- 「预算计划」中，每个小类独立选择按天、按月、按年。例如餐饮 20 元/天、会员 30 元/月、年费 120 元/年。
- 预计和实际都按同一周期填写。月/年实际整期只填一笔，同一周期内切换日历日期仍是同一条记录。
- 当前周期可以调整；日项目次日锁定，月项目下月锁定，年项目次年锁定。历史空缺仍仅可补录一次。
- 本期已有实际金额时，计费周期在下期再调整。旧的每日金额、历史和补录标记保留。
- 新增年展示。日/月统计按周期生效天数精确折算；完整周期合计等于输入金额，CSV 每周期只输出一行。

按自然月和自然年计算。月预算各月独立，年预算同年共用；同年编辑年预算会更新本年预算。首次从保存当天生效，过去的日记录不变。
