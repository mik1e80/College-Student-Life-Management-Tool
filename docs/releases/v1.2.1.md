# 一日有数 1.2.1 · 预算计划连续添加小类

在 **Assets** 下载 `yiri-1.2.1.apk`，直接覆盖安装。沿用原包名和发行签名，请勿先卸载或清除应用数据。

## 本次修复

- 修复预算计划中只能向空大类添加一次小类的问题。每个大类下始终保留「+ 添加小类」，添加后可在同一页继续操作，无需返回首页。
- 添加小类时保留当前预算月份和页面位置，已填写的金额、空白、0 元和天 / 月 / 年周期不会因重绘丢失。
- 添加小类仅保存新增分类，预算草稿须点击「保存预算计划」才保存。取消或重名失败时仍保留草稿。
- 防止添加时重复提交。历史月份继续只读，不显示添加入口。

预算、实际记录及周期锁定规则沿用 1.2.0。Android 8.0 及以上，需要可用的现代系统 WebView。应用仍可离线使用，不申请联网权限，也没有应用内自动更新入口。
