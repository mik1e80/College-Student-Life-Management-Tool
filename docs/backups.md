# 完整备份、恢复与迁移

适用版本：双衡 1.8.0。支持旧版直接导出的账本 JSON，以及新版带导出时间的完整备份。CSV 是查阅明细，不能用于恢复。

## 保存与恢复

1. 在原设备「我的账本」点击「下载完整备份 JSON」，保存到自己掌握的位置。
2. 在目标设备打开双衡「我的账本 → 恢复备份」，选择 JSON 文件。
3. 核对备份时间、大类、小类、实际金额记录、时间安排和闹钟数量。旧备份没有导出时间时会明确标注，不会猜测。
4. 勾选「我已核对，替换当前账本」，点击「确认完整恢复」。这是完整替换，不合并两份账本。
5. 核对金额和时间安排；任务提醒与闹钟恢复后默认关闭，请按需重新开启，并在手机设置允许相应提醒权限。

文件按 UTF-8 读取，上限 4 MiB。校验 JSON、版本、日期、金额、分类归属、唯一 ID、预算引用、时间重叠与闹钟设置。文件不合格、取消选择、未确认或保存失败，都不会部分覆盖账本。恢复预览后当前账本若变化，需要重新选择并核对。

## 找回恢复前的账本

确认恢复前，软件会自动保存当前账本的完整副本。如果副本无法保存，恢复会停止。点击「恢复前的账本」即可预览该副本，并按相同步骤恢复。只保留最近一次恢复前副本；再次恢复会将当前账本作为新的副本。它保存在本机，卸载、清理应用或浏览器数据会一起清除，不能代替单独保存的 JSON 文件。

安卓采用独立原子文件保存副本，主账本写入失败仍保留原文件；网页分别原子写入恢复副本和主存储，存储空间不足时停止并报错。恢复的 revision 高于当前和导入账本，避免旧镜像覆盖恢复结果。

## 网页与 APK 迁移

网页、不同浏览器、主屏幕网页与安卓 APK 的账本不自动同步。迁移时，在原账本导出 JSON，将文件传到目标设备或浏览器，再通过「恢复备份」选择。恢复前先导出目标端的重要数据，核对预览后再确认。整个导入在本机处理，不上传账本，也不要求账号登录。

安卓使用系统文档选择器，只读取你选择的文件，不申请联网或全盘存储权限。选择器打开时若应用被系统销毁，重新打开软件并重新选择，原账本不变。
