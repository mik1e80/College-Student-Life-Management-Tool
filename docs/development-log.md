## 2026-10-25 · 安卓安装包

用户进一步明确需要手机可下载的 APK，并希望大陆用户可打开下载网址。研究免费托管后，确认国内分发平台通常需要开发者本人注册和实名认证；用户暂不认证，随后明确接受将安装包发布到 GitHub。

完成 Java / WebView 离线安卓壳，内置账本页面，使用固定本地 HTTPS 来源和应用本地存储，不申请联网权限。增加原生返回、文件保存、确认框和系统栏适配，独立制作下载介绍页、隐私说明和安装引导。

本机没有 Android SDK，因此用 GitHub Actions 的 Android SDK 构建。首次构建因第三方 setup-android 默认请求已下线的 `tools` 包失败，改为只请求 `platform-tools` 后成功。Android 35 模拟器离线记账、重启持久化、返回、月计划及统计等检查通过。下载构建产物后在本机用长期保管的发行密钥签名，验证 v2 / v3 签名并生成 SHA-256；密钥和密码仅存忽略目录，没有进入仓库。

新增发布流程：对签名 APK 校验元数据、SHA-256 与 Android SDK 真实签名后，上传 GitHub Releases。正式发行说明见 [1.1.0](releases/v1.1.0.md)。大陆手机实际网络连通性尚未验证，不把公开链接当作大陆可达保证。

## 2026-10-25 · 天 / 月 / 年周期

用户指出单一每日预算不适合会员订阅，要求自行选择天、月、年；进一步确认实际金额也应按同一周期填写。新增逐项周期选择、整期实际记录、按周期锁定和一次补录；日/月/年展示及 CSV 避免重复计算整期金额。

数据升级为 schema 2，旧 schema 1 的日预算与日实际原样保留。新增 10 项周期与升级测试，加上既有规则共 28 项全部通过。Android 构建与模拟器工作流 `40170744177` 成功，覆盖旧账本升级、日/月/年保存、同月不同日期复用同一记录、系统返回和离线持久化。

本地浏览器用会员 30 元/月、实际 29 元验证节余 +1 元，用网盘 120 元/年、实际 118 元验证节余 +2 元；更换同月日期仍显示 29 元。安卓版本更新为 1.2.0 / versionCode 3，使用原证书签名，保留覆盖升级能力。签名、下载和网页发布结果见发行说明与验证记录。

## 2026-10-25 · 预算计划连续添加小类

用户反馈在预算计划的空大类中添加第一项后，添加入口消失，后续只能返回生活费首页添加。定位到入口仅在 `items.length === 0` 时渲染；同时原事件先调用离页确认，会丢弃未保存预算。

将添加入口独立于小类数量渲染，当前及未来月份的大类均可连续添加。打开弹窗时保留预算草稿，添加成功重绘后恢复金额原文、计费周期、滚动位置与未保存状态；新增小类单独保存，预算仍须主动提交。添加中防止重复提交，历史月份保持只读。

28 项既有测试通过。浏览器实际操作连续添加「洗衣液」「纸巾」，确认早餐 9.75、零食 0 元/月、洗衣液 25 元/月及新小类空白金额均保留；同名小类被拒绝后可改名继续添加。新增 Android 模拟器回归场景，覆盖空/非空大类的连续添加、草稿不被自动保存、取消、重名及历史月份只读。版本提升为 1.2.1 / versionCode 4；最终构建和发行证据见验证记录及发行说明。
