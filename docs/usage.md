# 手机使用说明

## 第一次使用

1. 打开[正式应用地址](https://campus-life-yiri-20261025.my-team-1261.chatgpt.site)，公开访问，无需登录。新账本内已有八个常用大类，餐饮中已有早餐、午餐、晚餐。
2. 在生活费首页进入大类，使用网格末尾的「添加小类」补充零食、文具等项目；也可在「预算计划」每个大类下直接连续添加，无需回首页。添加后保留当前月份、页面位置和未保存的金额、周期，预算仍需点击「保存预算计划」。历史预算月份只读。需要新大类时，在首页末格添加。
3. 打开「预算计划」，为每个项目选择「按天 / 按月 / 按年」，再填写该周期预计金额并保存。例如餐饮 20 元/天、会员 30 元/月、年费 120 元/年。
4. 回到「生活费」→ 大类 → 小类，填写本期实际并保存。按天每天一笔，按月每月一笔，按年每年一笔；同一月/年内点击不同日期，看到的是同一条记录。
5. 查看「支出统计」的日、月或年展示。月/年金额按该周期生效天数折算；本期详情直接对比完整金额。月预算各月独立设置，年预算同一年内共用。

分类建立后不删除。0 元需要主动填写；留空表示未记录。

## 查看历史与补录

在小类详情下半部点击日历日期。已结束的周期只读：按天次日锁定，按月下月锁定，按年次年锁定。若该小类在所选周期已生效且实际仍空缺，可补录一次，核对后立即锁定。本期已有实际金额时，周期选择会锁定；可在下一期调整，避免已有记录改变含义。

未来周期只能查看预算，不能预填实际。新的天、月或年各自从未记录开始。当前月/年内选择未来日期仍查看同一条本期记录，不会新建一笔。

## 升级到 1.2.1

下载新版 APK 后直接覆盖安装，包名与签名保持一致，已有每日记录自动兼容。请不要先卸载或清除应用数据。首次新增月/年项目从保存当天生效，不回写过去的日记录。按自然月、自然年划分周期；日/月统计折算不代表在每一天实际扣费。

## 添加到主屏幕

- iPhone / iPad：用 Safari 打开正式地址，轻点分享按钮，选择「添加到主屏幕」。
- 安卓：用支持 PWA 的浏览器打开正式地址，在浏览器菜单选择「安装应用」或「添加到主屏幕」。
- 也可在「我的账本」中点击安装入口查看提示。不同浏览器的菜单可能不同。

首次联网加载后会缓存应用资源。安装和离线能力受手机浏览器支持情况影响；本地 `localhost` 地址仅供当前电脑开发，不是手机访问地址。

## 保存备份

「我的账本」→「下载完整备份 JSON」保存分类、预算版本及实际记录。统计页面的「导出明细」可下载所选期间的 CSV，用表格软件查看。

当前数据只在这台设备、这个浏览器中保存。没有云同步，清理浏览器数据会清除账本。第一版可导出完整备份，暂不提供导入。安装到主屏幕后应确认原数据是否可见。
