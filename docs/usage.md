# 手机使用说明

## 第一次使用

1. 打开[正式应用地址](https://campus-life-yiri-20261025.my-team-1261.chatgpt.site)，公开访问，无需登录。新账本内已有八个常用大类，餐饮中已有早餐、午餐、晚餐。
2. 在生活费首页进入大类，使用网格末尾的「添加小类」补充零食、文具等项目。需要新大类时，在首页末格添加。
3. 打开「月计划」，为需要的项目填写每日预计金额，保存本月计划。月中开始使用，预算从今天生效；下个月单独安排。
4. 回到「生活费」→ 大类 → 小类，在实际金额中填写当天花费并保存。当天可调整。
5. 查看「支出统计」的日展示或月展示，了解实际开销与配对项目的预算差值。

分类建立后不删除。0 元需要主动填写；留空表示未记录。

## 查看历史与补录

在小类详情下半部点击日历日期。历史预算及已有实际金额只读。若该小类在那一天已存在且实际金额仍空缺，可填写一次，核对确认后立即锁定。

未来日期只能查看预算，不能填写实际花费。新的一天恢复空白记录，不会把昨日金额复制过来。

## 添加到主屏幕

- iPhone / iPad：用 Safari 打开正式地址，轻点分享按钮，选择「添加到主屏幕」。
- 安卓：用支持 PWA 的浏览器打开正式地址，在浏览器菜单选择「安装应用」或「添加到主屏幕」。
- 也可在「我的账本」中点击安装入口查看提示。不同浏览器的菜单可能不同。

首次联网加载后会缓存应用资源。安装和离线能力受手机浏览器支持情况影响；本地 `localhost` 地址仅供当前电脑开发，不是手机访问地址。

## 保存备份

「我的账本」→「下载完整备份 JSON」保存分类、预算版本及实际记录。统计页面的「导出明细」可下载所选期间的 CSV，用表格软件查看。

当前数据只在这台设备、这个浏览器中保存。没有云同步，清理浏览器数据会清除账本。第一版可导出完整备份，暂不提供导入。安装到主屏幕后应确认原数据是否可见。
