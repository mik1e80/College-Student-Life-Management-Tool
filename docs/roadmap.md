## 后续开发顺序

1. 每周时间模板：工作日/周末及按星期课程，应用后允许当天单独调整；冲突先预览，不覆盖已有安排。
2. 生活费预警：用户设置阈值，默认关闭高频提醒；未记录不当作 0 元，预算结余不当作银行余额。
3. 综合周报/月报：消费与预算、自由时间、未规划时长及环比；不对自由时间或未规划时间做负面评分。
4. 快捷记录与时间事件关联：从早餐等事件打开用户关联的小类，不自动生成消费。
5. 可选执行状态、生活费到账周期、选择性迁移和跨设备同步；先明确冲突与隐私规则。

暂不增加 AI 自动排程、排行榜、银行连接或复杂积分。本版没有宣称以上路线图功能已完成。
