# 任务提醒

在「时间规划 → 任务提醒」开启总开关，也可从「我的账本」进入。新任务默认开始前、结束前各 5 分钟；每一项分别选择不提醒、准点或提前 1/5/10/15/30/60 分钟。旧任务升级后不自动提醒，需要在修改安排时自行开启。

安卓打开应用时使用弹窗，退到后台或正常结束进程后使用系统通知。开启时按手机提示允许通知；如显示系统可能延迟，可点击「允许准时提醒」。通知的声音、悬浮横幅与锁屏显示由手机系统设置决定。勿扰、省电、系统强行停止可能延迟或阻止提醒；强行停止后需要重新打开应用。应用不申请悬浮窗、全屏打断或联网权限。

网页仅在页面打开且浏览器正常运行时弹窗，关闭、冻结或休眠后无法保证提醒。网页不申请后台推送权限。编辑窗口打开时先保留表单，关闭后再显示尚未过期的提醒；每条提醒去重。

跨日使用真实开始和结束日期，各提醒一次。短任务的结束提醒最早在任务开始时触发，避免在任务尚未开始前提示结束。已经错过提醒时刻的历史安排不批量补发；触发延迟超过任务边界 1 分钟时舍弃。复制昨天会复制提醒选项，生成独立任务。

修改时间或提醒选项后替换旧调度，删除任务、关闭某一项提醒或关闭总开关后取消对应提醒。总开关关闭不删除任务。安卓重启、更新应用、调整日期/时区后会根据本机账本重新安排。提醒回执保存在本机，账本备份包含提醒选项和总开关。

实现遵循 [Android 闹钟调度](https://developer.android.com/develop/background-work/services/alarms)、[通知权限](https://developer.android.com/develop/ui/views/notifications/notification-permission)和[通知渠道](https://developer.android.com/develop/ui/views/notifications/channels)规则。安卓仅保留一条下一次待触发闹钟，送达后接续后续任务，以避免大量任务占满系统闹钟名额。
